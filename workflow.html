Phase Details

StepPhaseAPI CallWhat happens
Preflight Pre GET /metadata/languages
POST /metadata/language/create		 Ensures all 5 locales are registered at org level. Runs once before the loop.
GET reward P1 GET /reward/{id}/brand/27 Fetches current locale list; identifies which of 5 are missing.
Clone & PUT P1 PUT /reward/{id}/brand/27 Missing locales are cloned from first available: en-roc → en-qc → en. PUT sends all 5 locales.
VERIFY P1 GET /reward/{id}/brand/27 Re-fetches; confirms all 5 locales are now present. Phase 2 is skipped if this fails.
GET fresh state P2 GET /reward/{id}/brand/27 New GET after Phase 1 ensures content is applied on top of the verified locale set.
Image update P2 — Applied to all 5 locales. HTTP URL → isExternal:true; other value → internal asset ID.
Text replacement P2 — "Banana Republic" → vendorName; X% → cashbackValue%. T&C skips % replacement.
PUT payload P2 PUT /reward/{id}/brand/27 All locales sent in one payload — en locale gets image updates only (no text replacement).
